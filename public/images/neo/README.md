# NEO landing images

Drop real product/lifestyle photos here (WebP recommended, ~1600px wide, optimized).
Until a file exists, `<NeoImage>` shows a labeled placeholder in its place.

Expected filenames used by the landing page:

- `neo-hero.webp` — hero product shot (NEO on a warm desk)
- `neo-desk.webp` — NEO beside a laptop, workspace
- `neo-focus.webp` — NEO with the focus/attention display
- `neo-voice.webp` — person talking to NEO
- `neo-companion.webp` — NEO as a friendly desk companion
- `neo-product-closeup.webp` — hardware close-up (LED ring / body)
- `neo-workspace.webp` — wide editorial workspace scene

No image URLs are hard-coded elsewhere — components reference `/images/neo/<file>`.
